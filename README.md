# ScamShield AI — Cybersecurity Awareness Platform

> **"Detect suspicious signs. Understand the risk. Stay safer online."**

**ScamShield AI** is a complete, beginner-friendly full-stack cybersecurity awareness and threat analysis platform. It inspects suspicious URLs, emails, SMS notices, and social engineering messages using **explainable rule-based heuristics** and optional plain-English **Groq AI** enrichment.

---

## 🛡️ Key Features

- **Multi-Mode Threat Scanner**:
  - **Mode A: URL Structural Analysis** — Static inspection of hostnames, IP-addresses, punycode, brand typosquatting, URL shorteners, deceptive `@` userinfo tricks, and non-HTTPS schemes.
  - **Mode B: Message & SMS Analysis** — Identifies manufactured urgency, extortion threats, requests for OTPs or passwords, gift card demands, fake parcel delivery notices, and bogus prize claims.
  - **Mode C: Combined Analysis** — Correlates URL and message signals without double-counting identical indicators.
- **SSRF-Protected Architecture**:
  - **Zero remote URL fetches** — ScamShield AI performs purely static textual and syntax analysis. It never connects to, visits, previews, or executes submitted targets, eliminating SSRF (Server-Side Request Forgery) vectors.
- **Transparent, Explainable Risk Engine**:
  - Normalizes risk to an intuitive **0–100 heuristic scale** categorized into:
    - `0–29`: **Low Observed Risk** (Green)
    - `30–59`: **Suspicious** (Amber)
    - `60–100`: **High Risk** (Red)
  - Provides a breakdown of triggered signals, "Why this matters" rationales, and safe next steps.
- **Optional Groq AI Summaries**:
  - Enriches detected indicators with plain-English conversational summaries.
  - **Prompt-Injection Resilient**: Untrusted user inputs are isolated and prevented from overriding rule-engine outputs.
  - Gracefully falls back to rule-based explanations if `GROQ_API_KEY` is omitted or offline.
- **Personal Dashboard & Analytics**:
  - Real-time statistics driven by actual PostgreSQL/SQLite records (zero fake statistics).
  - Risk distribution donut chart powered by Recharts.
  - Recent activity tracking and cybersecurity awareness tips.
- **Scan History Management**:
  - Search by keyword or target domain.
  - Filter by risk category and scan type; sort by newest, oldest, or highest risk.
  - Pagination, individual scan deletion with confirmation modals, and "Clear All" history purge.
- **Strict Privacy & Redaction**:
  - Candidate payment cards, 6-digit OTP codes, SSNs, and explicit password strings are automatically redacted before saving records.
- **Enterprise-Ready Authentication & Security**:
  - Secure password hashing with Argon2/bcrypt (12 rounds).
  - PyJWT access tokens transmitted via **HttpOnly, Secure, SameSite** cookies and Bearer headers.
  - User-isolated records: Users can only query and mutate their own scans.
  - Sliding-window in-memory rate limiting on authentication and scanning endpoints.
  - Role-protected Admin Console with privacy-preserving aggregated metrics.

## 🚀 Quickstart Guide for Beginners

### 1. Prerequisites
Ensure you have the following installed on your machine:
- **Node.js**: version `18.0` or higher (`node -v`)
- **Python**: version `3.11` or higher (`python --version` or `py -0`)
- **Git**: (`git --version`)

---

### 2. Opening the Project in Antigravity
Open Antigravity and set the active workspace to:
```text
C:\Users\zeena\.gemini\antigravity\scratch\scamshield-ai
```
*(Or your custom clone destination).*

---

### 3. Backend Setup

#### A. Navigate to backend directory
```bash
cd backend
```

#### B. Create a Virtual Environment
Using Python standard venv or `uv`:
```bash
# Standard Python
python -m venv .venv

# Windows activation
.venv\Scripts\activate

# macOS / Linux activation
source .venv/bin/activate
```

#### C. Install Dependencies
```bash
pip install -r requirements.txt
```

#### D. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
# Windows PowerShell
Copy-Item .env.example .env

# macOS / Linux / Bash
cp .env.example .env
```
Default `.env` settings:
```env
# Database: SQLite fallback works out-of-the-box:
DATABASE_URL=sqlite:///./scamshield.db

# To use PostgreSQL (Local or Hosted):
# DATABASE_URL=postgresql://username:password@localhost:5432/scamshield_db

JWT_SECRET_KEY=change-this-to-a-secure-random-string-min-32-chars
ACCESS_TOKEN_EXPIRE_MINUTES=60
COOKIE_SECURE=false
ENVIRONMENT=development
FRONTEND_ORIGIN=http://localhost:5173

# Optional: Groq AI integration (leave empty for pure rule engine)
GROQ_API_KEY=
GROQ_MODEL=llama-3.3-70b-versatile
```

#### E. Apply Database Migrations
Run Alembic to apply the latest database schema:
```bash
alembic upgrade head
```

#### F. Run the Backend Server
```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
- API Base: `http://127.0.0.1:8000/`
- Interactive OpenAPI Docs: `http://127.0.0.1:8000/docs`
- Redoc Documentation: `http://127.0.0.1:8000/redoc`

## 🧪 Running Automated Tests

ScamShield AI includes a 19-test automated test suite covering:
- User registration, duplicate email rejection, and password hashing.
- Login validation and invalid credential rejection.
- Session authorization and unauthorized access blocking.
- User scan isolation (User A cannot view or delete User B's scans).
- Static URL phishing indicator detection (IP hosts, brand spoofing, suspicious TLDs, `@` symbol tricks).
- Urgent SMS and email social engineering detection (OTP solicitation, gift card extortion, fake lotteries).
- High-volume input validation and string truncation.
- Search, filter, and database deletion.

```bash
cd backend
pytest -v
```

## 🐘 Configuring PostgreSQL (Optional)

By default, ScamShield AI runs on SQLite with zero manual setup. To connect a local or hosted PostgreSQL instance (e.g. Neon, Supabase, Render, AWS RDS):

1. Install PostgreSQL and create a database:
   ```sql
   CREATE DATABASE scamshield_db;
   ```
2. Update `backend/.env`:
   ```env
   DATABASE_URL=postgresql://postgres:yourpassword@localhost:5432/scamshield_db
   ```
3. Apply migrations to PostgreSQL:
   ```bash
   alembic upgrade head
   ```
4. Restart the backend. All models, indexes, and cascades will automatically initialize in PostgreSQL.

## 🤖 Configuring Optional Groq AI Integration

ScamShield AI functions completely without an AI API key. To add natural-language summaries:

1. Obtain a free API key from [Groq Console](https://console.groq.com/).
2. Add your key to `backend/.env`:
   ```env
   GROQ_API_KEY=gsk_your_groq_api_key_here
   GROQ_MODEL=llama-3.3-70b-versatile
   ```
3. Restart the backend server.
4. When performing an analysis in the UI, check **"AI Plain-English Enrichment"** to generate conversational explanations.

> **Security Guardrail:** The backend treats submitted text as untrusted data with strict system prompt boundaries. The LLM is instructed never to obey instructions in submitted messages and never to contradict detected rule indicators.

## 🌐 Production Deployment Guide

### 1. Database (Hosted PostgreSQL)
- Create a managed PostgreSQL database on **Neon**, **Supabase**, or **AWS RDS**.
- Copy the provided connection string (e.g. `postgresql://user:password@ep-host.neon.tech/neondb?sslmode=require`).

### 2. Backend (Render / Railway / Fly.io / AWS)
- Set Environment Variables on your hosting provider:
  - `DATABASE_URL`: Your hosted PostgreSQL connection URL
  - `JWT_SECRET_KEY`: Generate a random 64-char key (`openssl rand -hex 32`)
  - `COOKIE_SECURE`: `true`
  - `ENVIRONMENT`: `production`
  - `FRONTEND_ORIGIN`: `https://your-frontend-domain.com`
  - `GROQ_API_KEY`: *(Optional)*
- Build command: `pip install -r requirements.txt && alembic upgrade head`
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

### 3. Frontend (Vercel / Netlify / Cloudflare Pages)
- Set Environment Variables:
  - `VITE_API_BASE_URL`: `https://your-backend-api.com/api`
- Build command: `npm run build`
- Output directory: `dist`

## ⚠️ Security Notice & Educational Limitations

- **Educational Tool:** ScamShield AI is designed to heighten user awareness and help spot common deception indicators.
- **Provisional Heuristics:** Heuristic risk scores reflect observed patterns, not mathematical certainty. Cybercriminals frequently invent novel evasion techniques.
- **Out-of-Band Verification:** Never trust an unsolicited message or unfamiliar URL without independently verifying with the authentic institution via known official contact numbers or bookmarks.
